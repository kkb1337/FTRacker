# FTracker v1.8.89 — iOS keyboard + packaging fix

Дата релиза: 15.10.2026

## v1.8.89
- **Клавиатура в тренировке.** В iOS PWA клавиатура не уменьшает layout viewport, поэтому нижние поля оказывались под ней и не прокручивались. Теперь высота клавиатуры из `visualViewport` пишется в `--ft-kb`, список упражнений получает такой же нижний отступ, а строка подхода центрируется в видимой части экрана. Тап вне полей закрывает клавиатуру.
- **Стили.** `index.html` ссылался на несуществующий `ui_refactor_1.8.88.css`: весь UI-слой не загружался. Файл теперь называется `ui_refactor.css` (без версии в имени) — кэш сбрасывается параметром `?v=`. Старый `ui_refactor_1.8.8x.css` из репозитория нужно удалить.
- **Service Worker.** `ui_refactor.css` добавлен в обработчик fetch — без этого стили не отдавались из кэша офлайн.
- **Рекорды.** Проверка рекорда больше не срабатывает на каждый символ (ввод «100» засчитывался как рекорд «1 кг»); теперь она выполняется по завершении ввода (`change`).
- `audit-tests.js` синхронизирован с версией и проверяет, что все файлы из `index.html` существуют.

## Что изменено
- Выпущена версия **1.8.87**: синхронизированы метаданные версии, cache-busting URL и версия оболочки Service Worker. Бизнес-логика и формат пользовательских данных не менялись.
- Регрессионные проверки синхронизированы с версией 1.8.87.
- Добавлен финальный UI-слой `ui_refactor_1.8.87.css`: единые токены Light/Dark, iOS safe-area/AppBar, типографика, карточки, кнопки, поля, tabs, модальные окна и компактные workout-состояния. Бизнес-логика не менялась.
- Навигация главного экрана приведена к единому вертикальному стеку без межстрочных провалов; заголовки экранов и кнопка возврата унифицированы.
- Theme Color PWA синхронизируется с выбранной темой.
- **Анимации упражнений вынесены из `app.js` в корневые файлы `*-N.webp` (без подпапок, для загрузки на GitHub Pages через веб-интерфейс).** Раньше ~6 МБ base64 лежали прямо в коде и разбирались при каждом запуске. `app.js`: 6,7 МБ → ~0,7 МБ. Удалены 6 дублей изображений, которые перекрывались одноимёнными ключами.
- **`styles.css`: 718 → ~555 КБ.** Удалено ~4 250 деклараций, которые гарантированно перекрыты более поздним правилом с тем же селектором. Вычисленные стили всех элементов (тёмная и светлая темы) совпадают с прежними.
- **Service Worker переписан.** Запуск из кэша без ожидания сети; картинки кэшируются лениво при первом открытии (`ftracker-media-v1`, не сбрасывается при обновлении версии); оболочка прекэшируется с обходом HTTP-кэша.
- **`index.html`:** убраны `no-cache`/`Pragma`/`Expires` (конфликтовали с офлайн-режимом), дубли мета-тегов; добавлены `apple-touch-icon.png` (180×180), `mobile-web-app-capable`, `format-detection`.
- **`manifest.json`:** убрано нестандартное `appVersion`, добавлен `lang`.
- Убрана повторная регистрация/проверка обновления Service Worker и логи в консоль.
- README очищен от истории прежних версий.

- Полностью исправлен блок периода на экране «Прогресс»: кнопки 30/90/Всё время теперь занимают всю ширину и не конфликтуют со старой grid-разметкой.
- Переработана визуальная иерархия экрана «Прогресс»: компактнее сводка, аккуратнее блок тренда, без пустой пятой ячейки и вложенных рамок.
- Старые конфликтующие правила `.progress-ex-period` удалены из основного CSS; один владелец разметки периода — `ui_refactor_1.8.87.css`.

## Что не менялось
Логика тренировок, формулы Индекса, рабочий вес, таймер, формат данных и ключи localStorage/IndexedDB.

## Обновление
Новая версия подхватывается в фоне и применяется при следующем запуске приложения.

## Проверки
`node --check app.js` и `node audit-tests.js`.
